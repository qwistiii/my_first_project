# Бот «Вирты Black Russia»

Телеграм-бот, который показывает по каждому серверу игровой онлайн и цену за
1 кк виртов на FunPay. Работает круглосуточно и бесплатно: данные собирает
GitHub Actions по расписанию, отвечает на сообщения Cloudflare Worker.

```
GitHub Actions (раз в 15 мин)          Cloudflare Worker
  bot/collect.py                         bot/worker.js
  ├─ SA-MP запрос к 91 серверу  ──┐      ├─ вебхук Telegram
  └─ цены с funpay.com/chips/186  │      └─ читает data/servers.json,
                                  ▼         держит в кеше 4 минуты
                        data/servers.json ──┘
```

Бот никогда не ходит на FunPay в ответ на сообщение — только в свой кеш.
Поэтому он отвечает мгновенно и не создаёт нагрузки на чужие сайты.

## Что показывает

| Команда | Что делает |
| --- | --- |
| `/best` | Где выгоднее фармить: индекс «игроков × цена ÷ 1000» |
| `/cheap` | Где дешевле купить |
| `/top` | Самые населённые серверы |
| `/s blue`, `/s 42` | Карточка одного сервера |

### Почему две цены, а не одна

Самая низкая цена в списке на каждом пятом сервере недостижима: её держат
продавцы без единого отзыва или с оптовым минимумом заказа. Пример с сервера
Blue: дешевле всех 42.77 ₽ — продавец с нулём отзывов и минимумом 72 кк;
следующая цена 43.99 ₽ — продавец с 65 отзывами и минимумом 1 кк.

Поэтому бот показывает обе: абсолютный минимум и минимум у продавца, у
которого реально можно купить, — и объясняет, чем они отличаются. Порог
доверия задан в `collect.py` (`MIN_REVIEWS`, `MAX_MIN_ORDER_KK`).

### Почему индекс, а не цена

Онлайн сервера и цена виртов идут в разные стороны (корреляция −0.42): чем
больше игроков, тем больше нафармленного вирта, тем ниже цена. Поэтому самая высокая цена обычно означает пустой сервер, где фармить нечего. Сортировка по
индексу учитывает оба множителя.

## Установка

### 1. Репозиторий

Форкните или скопируйте этот репозиторий к себе. **Сделайте его публичным** —
у публичных репозиториев минуты GitHub Actions не ограничены, у приватных
лимит 2000 минут в месяц, и сбор каждые 15 минут в него не уложится.

Включите Actions: вкладка **Actions** → **I understand my workflows, go ahead
and enable them**. Первый сбор можно запустить руками: **Actions → Сбор данных
о серверах → Run workflow**.

После него проверьте, что появился `data/servers.json` и в нём заполнено поле
`online`.

### 2. Бот в Telegram

Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите токен
вида `123456:AA...`.

### 3. Cloudflare Worker

Регистрация на [dash.cloudflare.com](https://dash.cloudflare.com) бесплатна и
без карты. Далее **Workers & Pages → Create → Worker**, назовите, например,
`br-virts-bot`, и вставьте содержимое `bot/worker.js` в редактор. Deploy.

В **Settings → Variables and Secrets** добавьте:

| Имя | Тип | Значение |
| --- | --- | --- |
| `BOT_TOKEN` | Secret | токен от BotFather |
| `WEBHOOK_SECRET` | Secret | любая случайная строка, придумайте сами |
| `DATA_URL` | Text | `https://raw.githubusercontent.com/<логин>/<репозиторий>/main/data/servers.json` |

### 4. Связать бота с воркером

Один раз выполните в терминале, подставив свои значения:

```bash
curl "https://api.telegram.org/bot<ТОКЕН>/setWebhook" \
  -d "url=https://<имя-воркера>.<ваш-поддомен>.workers.dev" \
  -d "secret_token=<WEBHOOK_SECRET>"
```

В ответ должно прийти `{"ok":true,...}`. Напишите боту `/start`.

## Ограничения, о которых стоит знать заранее

- **Расписание GitHub Actions неточное.** Запуск раз в 15 минут — это
  пожелание, а не гарантия: под нагрузкой GitHub задерживает запуски на
  десятки минут. Поэтому бот всегда пишет фактическое время сбора, а после
  45 минут без обновления помечает данные как устаревшие.
- **Actions отключаются от простоя.** Если в репозитории 60 дней не будет
  коммитов, GitHub выключит расписание и пришлёт письмо. Сборщик коммитит
  данные при каждом изменении, так что на практике это не наступает.
- **Порт SA-MP не подтверждён.** `collect.py` пробует 7777, затем 5125.
  Проверьте на первом запуске, сколько серверов ответило (`online_answered`
  в `data/servers.json`). Если ноль — узнайте настоящий порт и поправьте
  `SAMP_PORT`.
- **Правила проекта я прочитать не смог.** `robots.txt` сайта Black Russia
  закрыт той же защитой, что и всё остальное. Данные публичные, но посмотрите
  пользовательское соглашение сами и решите, годится ли вам такой сбор.
- **Цены живут своей жизнью.** За день лидеры меняются; принимая решение,
  смотрите на дату обновления, а не на память.
