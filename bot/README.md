# Бот «Вирты Black Russia»

Телеграм-бот: по каждому серверу показывает игровой онлайн и цену за 1 кк
виртов на FunPay. Работает круглосуточно и бесплатно, своего сервера не нужно.

```
GitHub Actions (раз в 15 мин)          Cloudflare Worker
  bot/collect.py                         bot/worker.js
  ├─ онлайн с blackrussia.online ─┐      ├─ вебхук Telegram
  └─ цены с funpay.com/chips/186  │      └─ читает data/servers.json,
                                  ▼         держит в кеше 4 минуты
                        data/servers.json ──┘
```

Бот не ходит на FunPay в ответ на сообщение — только в свой кеш. Поэтому
отвечает мгновенно и не создаёт нагрузки на чужие сайты: одна загрузка каждой
страницы раз в 15 минут, 96 обращений в сутки.

## Команды

| Команда | Что делает |
| --- | --- |
| `/best` | Где выгоднее фармить: индекс «игроков × цена ÷ 1000» |
| `/cheap` | Где дешевле купить |
| `/top` | Самые населённые серверы |
| `/s blue`, `/s 42` | Карточка одного сервера |

## Установка: четыре шага

Программировать не нужно, всё делается мышкой. Терминал не понадобится.

### Шаг 1. Репозиторий

Сделайте репозиторий **публичным**: Settings → General → внизу Danger Zone →
Change visibility. У публичных репозиториев минуты GitHub Actions не
ограничены, у приватных лимит 2000 в месяц, и сбор каждые 15 минут в него не
уложится.

Код должен лежать в **ветке по умолчанию** (обычно `main`) — расписание
Actions работает только в ней.

Откройте вкладку **Actions** и нажмите «I understand my workflows, go ahead
and enable them». Затем **Сбор данных о серверах → Run workflow**, чтобы
проверить первый запуск: в логе должно быть `онлайн: 91/91`.

### Шаг 2. Бот в Telegram

Напишите [@BotFather](https://t.me/BotFather) команду `/newbot`, придумайте имя.
В ответ придёт токен вида `123456:AA...` — скопируйте его.

### Шаг 3. Cloudflare

Регистрация на [dash.cloudflare.com](https://dash.cloudflare.com) бесплатная,
карта не нужна.

1. **Workers & Pages → Create → Worker**, имя, например, `br-virts-bot`, Deploy.
2. **Edit code**: удалите содержимое и вставьте туда весь файл `bot/worker.js`.
   Deploy.
3. **Settings → Variables and Secrets** — добавьте три записи:

| Имя | Тип | Значение |
| --- | --- | --- |
| `BOT_TOKEN` | Secret | токен из шага 2 |
| `WEBHOOK_SECRET` | Secret | любая случайная строка, придумайте сами |
| `DATA_URL` | Text | `https://raw.githubusercontent.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ/main/data/servers.json` |

4. Скопируйте адрес воркера сверху страницы — вида
   `https://br-virts-bot.ваш-поддомен.workers.dev`.

### Шаг 4. Связать бота с воркером

В GitHub: **Settings → Secrets and variables → Actions → New repository secret**,
добавьте три секрета — `BOT_TOKEN`, `WEBHOOK_SECRET` (те же значения, что в
Cloudflare) и `WORKER_URL` (адрес из шага 3).

Затем **Actions → «Подключить бота к воркеру» → Run workflow**. Он сам пропишет
вебхук. В логе должно быть `"ok":true`.

Напишите боту `/start`.

## Почему две цены, а не одна

Самая низкая цена в списке **на каждом пятом сервере недостижима**: её держат
продавцы без единого отзыва или с оптовым минимумом заказа. Пример с Podolsk:
дешевле всех 28.86 ₽, но минимум заказа 22 кк; следующая доступная — 42.77 ₽ у
продавца с 244 отзывами.

Бот показывает обе цены и подписывает, чем они отличаются. Пороги доверия
задаются в `collect.py` — `MIN_REVIEWS` и `MAX_MIN_ORDER_KK`.

## Почему индекс, а не цена

Онлайн сервера и цена виртов идут в разные стороны (корреляция −0.42): больше
игроков — больше нафармленного вирта — ниже цена. Поэтому высокая цена обычно
означает пустой сервер, где фармить нечего, а сортировка по одной цене
обманывает. Индекс учитывает оба множителя.

## Что стоит знать заранее

- **Расписание Actions неточное.** Раз в 15 минут — пожелание, а не гарантия:
  под нагрузкой GitHub задерживает запуски. Поэтому бот пишет фактическое
  время сбора, а после 45 минут без обновления ставит ⚠️.
- **Сайт пускает не с первой попытки.** Он закрыт защитой от ботов, браузер
  проходит её примерно с третьей попытки — сборщик повторяет до шести раз.
  Если однажды не выйдет, данные не перезапишутся нулями: останутся прошлые с
  честной отметкой времени.
- **Actions отключаются от простоя.** Если 60 дней не будет коммитов, GitHub
  выключит расписание и пришлёт письмо. Сборщик коммитит при каждом изменении,
  так что на практике это не наступает.
- **Правила проекта я прочитать не смог.** `robots.txt` сайта Black Russia
  закрыт той же защитой, что и всё остальное. Данные публичные, но
  пользовательское соглашение посмотрите сами и решите, годится ли вам такой
  сбор.

## Проверка без Telegram

`node bot/test/worker.test.mjs` прогоняет все команды бота на реальном
`data/servers.json` и печатает ответы в терминал — ни Telegram, ни Cloudflare
для этого не нужны.
